# Editores
Visual Studio Code, Sublime Text, Vim, Notepad++, outros.
# Vantagens
Destaca a sintaxe, autocompleta o código, organiza o código, informa erros e mais.

## Utilizado
Visual Studio Code

- **IDENTAR O CÓDIGO**
    
    SHIFT + ALT + F
    
- **ACESSAR O MENU**
    
    SHIFT + CTRL + P
    
- **CLONAR O ELEMENTO**
    
    SHIFT + ALT + BAIXO
    
- **COPIAR**
    
    CTRL + C
    
- **COLAR**
    
    CTRL + V
    
- **RECORTAR**
    
    CTRL + X
    
- **VOLTAR AO ESTADO ANTERIOR - DESFAZER**
    
    CTRL + Z
    
- **VOLTAR AO ESTADO DESFEITO**
    
    CTRL + SHIFT + Z
    
- **ANDAR COM A LINHA**
    
    ALT + SETAS
    
- **SELECIONAR TAGS IGUAIS EM CONJUNTO OU INDIVIDUALMENTE**
    
    CTRL + D
    
- **COMENTAR SIMPLIFICADAMENTE**
    
    CTRL + /
    
- **EXIBIR/OCULTAR O EXPLORADOR DE ARQUIVOS**
    
    CTRL + B
    
- **EXIBIR/OCULTAR  A BARRA DE ATIVIDADE (INCLUÍDO PELA CONFIGURAÇÃO)**
    
    SHIFT + K
    
- **DEBUGAR CÓDIGO**
    
    Primeiro aperte F5, clicar na linha final ao lado do código, F10 para analisar o linha por linha, F11 para entrar dentro do método.
    
    **F5:** Começar a debuggar seu código
    
    **F10:** Analisar linha sem entrar no código interno
    
    **F11:** Analisar linha e entrar no código interno
    
    **SHIFT + F11:** para sair do bloco de código atual e continuar a execução.
    
- **PRÉ-VISUALIZAR**
    
    CTRL + SHIFT + V
    
- **ABRIR  O TERMINAL**
    
    CTRL + ‘
    
- **RODAR**
    
    CTRL + ALT + N
